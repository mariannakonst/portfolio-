AI Support Assistant for Jira

Team project · assistant for support consultants and team leaders

Overview

NSS Navigator is an application that helps a support team handle Jira tickets faster. It analyzes incoming tickets with AI, suggests similar past cases and knowledge-base articles, and shows reporting screens for service levels (SLA) and team workload. Consultants use it through a Chrome extension placed next to the ticket they are working on.

Team Project

This was a team effort: the core application was developed together with colleagues, and I contributed to specific parts of it (see My Contribution below). The application is used internally by a pilot group of users. For confidentiality, all screenshots on this page are illustrations made with sample data, not real customer or company data.

How the Application Works

1. Ticket Analysis

When a ticket arrives, the application reads it and prepares an analysis for the consultant, with a suggested next step.

2. Knowledge Search

Similar past cases and documentation articles are found using embeddings and AI, so the answer is easier to find.

3. Chrome Extension

The result appears in a side panel in the browser, directly inside Jira, without switching tools.

4. Reports

Team leaders see SLA monitoring and workload screens with filters for project, team, user group, consultant, time type and label.
