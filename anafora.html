Timesheet Analytics Dashboard

Interactive dashboard for time tracking analysis and operational reporting.

Overview

The application provides a centralized dashboard for analyzing Jira timesheet data stored in a SQL Server database. It retrieves project, issue, assignee and time tracking information, allowing users to explore operational metrics through interactive filters, pivot tables and downloadable Excel reports.

How the Application Works

  1. Connects to a SQL Server database.
  2. Retrieves Jira projects, issues, users and time tracking records.
  3. Processes the data using Pandas.
  4. Allows filtering by project, assignee, customer, partner, component and date.
  5. Generates dynamic pivot tables and summarized reports.
  6. Exports the results as Excel Pivot reports.

Main Features

  • SQL Server database integration
  • Interactive Streamlit interface
  • Advanced filtering
  • Dynamic Pivot Tables
  • Time calculations and summaries
  • Jira ticket links
  • Excel Pivot export
